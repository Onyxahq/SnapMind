## SnapMind が手放せなくなる理由

スクショ用、文字起こし用、翻訳用、画面録画用……いくつもの重いアプリを行き来していませんか？ **わずか約 10 MB の SnapMind がすべてを 1 つに置き換えます。**

- **海外のアプリ、ゲーム、PDF、エラー画面が読めない？** 範囲を囲むだけで、**翻訳結果を元の画像の上にそのまま重ねて表示**。背景色や文字サイズも自動でなじみます。
- **画像やスライドの中の表を Excel に写したい？** もう手入力は不要。**ワンクリックで表を認識し、結合セルを保ったまま Excel / Word にそのまま貼り付け**できます。
- **参考画像を画面の端にずっと置いて作業したい？** **最前面にピン留め**するだけ。しかも、ピン留めした画像から直接テキストをドラッグ選択してコピーできます。
- **長いWebページや操作手順の共有も一瞬** — **スクロール撮影も MP4 / GIF 録画も標準搭載**です。

## 30秒でダウンロード＆インストール

> **👉 [GitHub Releases から最新版をダウンロード](https://github.com/Onyxahq/SnapMind/releases/latest)**

1. **[Releases ページ](https://github.com/Onyxahq/SnapMind/releases/latest)** から最新の `SnapMind_<バージョン>_x64-setup.exe`（約 **10 MB**）をダウンロードします。
2. ダブルクリックしてインストール（**Windows 10 / 11 64-bit** 対応）。
3. 初回起動ガイドに従って、必要に応じて**無料のオフライン文字認識パック（約 21 MB）**を取得したり、お好みの AI を設定するだけですぐに使えます。

## 主な魅力 6 選

### 1. 一瞬で撮れて、注釈も快適
- **`Shift+F1`** でマルチモニターでも瞬時に画面を静止。ウィンドウやボタンに自動で吸着します。
- 拡大鏡＆カラーピッカー、矢印、枠線、マーカー、文字、番号スタンプ、きれいなモザイクを搭載。コピー1回でチャットや資料にそのまま貼れます。

### 2. ネット不要・無料の高精度文字認識（テキスト・表・数式・Markdown）
- **完全オフライン**：日本語・英語・中国語・韓国語などを無料で高精度に読み取り。画像が外部サーバーに送られることはありません。
- **必要な行だけ選べる**：検出枠をクリックして、コピーしたい行だけをピックアップ可能。
- **表をそのまま Excel へ**：その場でセル編集し、Excel / Word へ直接コピー、または `.xlsx` 書き出し。
- **数式や記事もきれいに変換**：数式は LaTeX へ、記事は読みやすい Markdown へ変換できます。

### 3. 文脈がわかるスマート AI 翻訳
- **画像上への直接翻訳**：コードや数字・数式を避けながら、画像上のテキストだけを自然に翻訳。
- **どこでも選択翻訳（`Ctrl+Alt+D`）**：文字を選んで押すだけでカーソル横に翻訳カードを表示。ピン留めすれば連続で調べられます。
- **24以上のAI・翻訳サービスに対応**：ChatGPT、Claude、Gemini、DeepSeek、DeepL、Google翻訳、Microsoft翻訳、さらにローカルAI（**Ollama / LM Studio**）まで対応。混雑時の自動フォールバックも設定可能。

### 4. 作業効率が上がるピン留めウィンドウ
- **`Ctrl+T`** でスクショを最前面に固定、**`Shift+F3`** でクリップボードの画像やテキストも即ピン留め。
- 貼った画像の文字を自動で認識し、**そのままコピー可能**。拡大縮小・半透明化・クリックスルー・履歴復元まで完備。

### 5. スクロール長尺撮影＆かんたん画面録画
- **スクロール撮影（`L`）**：長いページやチャット履歴を1枚の画像に自動結合。スクロールバーや固定ヘッダーもすっきり除去。
- **画面録画（`R`）**：指定範囲をシステム音声付き **MP4** や **GIF** で録画。停止と同時にファイルがクリップボードにコピーされ、そのまま送信できます。

### 6. 軽快・美しいデザイン・安心のプライバシー
- **約 10 MB の軽量設計**、ライト／ダークテーマ＆4色のアクセントカラー、10言語対応。
- オフライン文字認識はPC内で完結。APIキーも Windows の安全な資格情報マネージャーに保管されます。

## まずはこの 5 つのショートカットだけ

| ショートカット | 機能 |
| --- | --- |
| **`Shift+F1`** | スクリーンショット（注釈・文字認識・翻訳・長尺・録画） |
| **`Shift+F3`** | クリップボードの画像や文字をピン留め |
| **`Ctrl+Alt+D`** | 選択中のテキストを翻訳 |
| **`Ctrl+Shift+S`** | 撮ってすぐ文字認識＆コピー |
| **`Ctrl+Shift+O`** | 撮ってすぐ翻訳 |
