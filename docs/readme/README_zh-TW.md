## 為什麼用過 SnapMind 就回不去了？

以前為了截圖、抓圖裡的文字、翻譯外語介面、錄一段教學影片，電腦總要裝上三四套肥大軟體。**現在，一個 10 MB 的 SnapMind 全部包辦：**

- **看到外語網頁、遊戲介面、PDF 論文或錯誤視窗？** 框一下，**譯文直接覆蓋在原圖上**，底色與字體大小自動對齊，自然得像原本就是中文！
- **截圖或簡報裡有一大張表格，不想重打進 Excel？** 一鍵辨識並直接編輯，**複製貼上到 Excel / Word，連合併儲存格都完整保留**！
- **寫報告、查資料時想把參考圖一直放在最上層？** **一鍵釘選在螢幕最前面**，還能直接從貼圖上反白複製文字、畫重點、調透明度！
- **網頁太長截不完？想錄個短片傳給同事？** **捲動長截圖 + 區域錄影（MP4 / GIF）一次內建**，錄完自動複製到剪貼簿，貼上就送出！

## 六大亮點功能

### 1. 秒開截圖與俐落標註
- 按 **`Shift+F1`** 瞬間凍結畫面，多螢幕、高解析度同樣順手。
- 自動對齊視窗與按鈕；內建放大鏡取色、箭頭、框線、螢光筆、文字、步驟編號與清晰馬賽克。

### 2. 斷網也能用的免費高精準辨識（文字 · 表格 · 公式 · Markdown）
- **完全離線且免費**：辨識中、英、日、韓等多國文字不需聯網、不花錢、不外傳隱私。
- **只抓你需要的句子**：辨識後可直接在圖上點選要保留或略過哪幾行。
- **表格直貼 Excel**：即時預覽與修改儲存格，一鍵貼入 Excel / Word 或匯出 `.xlsx`。
- **公式與文章排版**：數學公式轉 LaTeX、長文一鍵轉成整齊的 Markdown 筆記。

### 3. 真正讀懂語境的 AI 翻譯
- **原圖覆蓋翻譯**：直接把譯文貼回原圖對應位置，自動跳過程式碼、數字與公式。
- **隨處劃詞翻譯（`Ctrl+Alt+D`）**：在任何軟體選取文字即可在游標旁彈出可拖動譯文卡，釘選後可連續查詞。
- **支援 24+ 主流 AI 與翻譯引擎**：ChatGPT、Claude、Gemini、DeepSeek、DeepL、Google / 微軟翻譯，以及本機 **Ollama / LM Studio**，還支援多線路自動備援。

### 4. 超好用的螢幕置頂貼圖
- 按 **`Ctrl+T`** 釘選截圖，或按 **`Shift+F3`** 把剪貼簿的圖片/文字直接釘在螢幕上。
- 貼圖會自動辨識文字，**直接拖曳就能複製圖中文字**；支援滾輪縮放、調透明度、原位標註與滑鼠穿透。
- 內建歷史紀錄與當機自動復原，不怕誤關找不到。

### 5. 捲動長截圖與輕量錄影
- **捲動長截圖（`L`）**：自動或手動捲動拼接長網頁、聊天紀錄，自動去除捲軸與重複頁首。
- **區域錄影（`R`）**：錄製含系統聲音的 **MP4** 或 **GIF**，停止即自動複製檔案到剪貼簿。

### 6. 輕巧、高顏值、守住隱私
- 安裝檔僅約 **10 MB**；淺色 / 深夜模式與 4 種主題色，內建 10 國語言，工具列與快捷鍵完全自訂。
- 離線辨識不上雲端，API 金鑰僅安全存放在 Windows 系統憑證管理員中。

## 10 秒記住 5 個最常用快捷鍵

| 快捷鍵 | 用途 |
| --- | --- |
| **`Shift+F1`** | 開始截圖（標註 / 識字 / 翻譯 / 長截圖 / 錄影） |
| **`Shift+F3`** | 把剪貼簿裡的圖片或文字直接釘在螢幕上 |
| **`Ctrl+Alt+D`** | 劃詞翻譯 |
| **`Ctrl+Shift+S`** | 截圖並立即識字複製 |
| **`Ctrl+Shift+O`** | 截圖並立即翻譯 |
