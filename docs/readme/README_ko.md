## 왜 다들 SnapMind로 갈아탈까요?

캡처 따로, 글자 추출 따로, 번역 따로, 화면 녹화 따로 쓰고 계셨나요? **단 10 MB의 가벼운 SnapMind 하나로 모든 작업이 끝납니다.**

- **외국어 프로그램, 게임, PDF, 오류 창이 답답할 때** — 드래그만 하면 **번역문이 원본 이미지 위에 자연스럽게 덮여 표시**됩니다.
- **이미지 속 복잡한 표를 엑셀로 옮겨야 할 때** — 일일이 타이핑하지 마세요. **클릭 한 번으로 표를 인식해 셀 병합까지 유지한 채 Excel / Word에 바로 붙여넣기**할 수 있습니다.
- **참고 자료를 화면 맨 위에 띄워 두고 작업하고 싶을 때** — **화면 고정(핀)** 기능으로 띄워 두고, 고정된 이미지 안의 글자도 바로 드래그해서 복사하세요.
- **긴 웹페이지나 짧은 설명 영상이 필요할 때** — **스크롤 캡처와 MP4 / GIF 화면 녹화**가 기본 내장되어 있습니다.

## 30초 만에 다운로드 및 설치

> **👉 [GitHub Releases에서 최신 버전 다운로드하기](https://github.com/Onyxahq/SnapMind/releases/latest)**

1. **[Releases 페이지](https://github.com/Onyxahq/SnapMind/releases/latest)**에서 최신 `SnapMind_<버전>_x64-setup.exe`(약 **10 MB**)를 다운로드합니다.
2. 더블 클릭해 설치하세요 (**Windows 10 / 11 64비트** 지원).
3. 처음 실행 시 안내에 따라 **무료 오프라인 문자 인식 팩(약 21 MB)**을 받거나 원하는 AI 서비스를 연결하면 바로 사용할 수 있습니다.

## 핵심 기능 6가지

### 1. 즉각적인 캡처와 깔끔한 주석
- **`Shift+F1`**을 누르는 순간 멀티 모니터에서도 화면이 즉시 고정되며 창과 버튼에 자동으로 맞춰집니다.
- 돋보기·색상 추출기, 화살표, 도형, 형광펜, 텍스트, 순서 번호, 깔끔한 모자이크까지 모두 지원합니다.

### 2. 인터넷 없이도 무료로 쓰는 고정밀 인식 (텍스트 · 표 · 수식 · Markdown)
- **100% 오프라인 무료**: 한국어·영어·중국어·일본어 등을 서버 전송 없이 안전하고 정확하게 인식합니다.
- **원하는 줄만 콕 집어 복사**: 인식된 문장 박스를 클릭해 필요한 줄만 선택할 수 있습니다.
- **표는 바로 Excel로**: 미리보기에서 바로 수정하고 Excel / Word에 복사하거나 `.xlsx` 파일로 저장하세요.
- **수식 & 문서 정리**: 수학 수식은 LaTeX로, 긴 글은 깔끔한 Markdown으로 변환합니다.

### 3. 문맥을 이해하는 스마트 AI 번역
- **이미지 원위치 덮어쓰기 번역**: 코드·숫자·수식은 건드리지 않고 필요한 문장만 원본 배경색에 맞춰 깔끔하게 번역합니다.
- **어디서나 드래그 번역 (`Ctrl+Alt+D`)**: 어떤 앱에서든 텍스트를 선택해 단축키를 누르면 커서 옆에 깔끔한 번역 카드가 뜹니다.
- **24개 이상의 AI 및 번역 엔진 지원**: ChatGPT, Claude, Gemini, DeepSeek, DeepL, Google·Microsoft 번역, 로컬 AI(**Ollama / LM Studio**)까지 모두 연결 가능하며 자동 백업 전환을 지원합니다.

### 4. 작업 효율을 높여 주는 화면 고정(핀)
- **`Ctrl+T`**로 캡처를 최상단에 고정하거나 **`Shift+F3`**로 클립보드 이미지/텍스트를 바로 띄우세요.
- 고정된 이미지의 텍스트를 자동 인식해 **바로 드래그 복사**할 수 있으며, 확대/축소·투명도 조절·클릭 통과·기록 복구까지 지원합니다.

### 5. 스크롤 긴 캡처 & 간편 화면 녹화
- **스크롤 캡처 (`L`)**: 긴 채팅방이나 웹페이지를 스크롤바와 상단 고정 바 없이 깔끔한 한 장으로 이어 붙입니다.
- **화면 녹화 (`R`)**: 원하는 영역을 시스템 소리 포함 **MP4** 또는 **GIF**로 녹화하고, 종료 즉시 클립보드에 복사해 바로 전송하세요.

### 6. 가볍고, 아름답고, 안전한 프라이버시
- **약 10 MB 초경량 설치**, 라이트/다크 테마와 4가지 강조 색상, 10개 언어 지원.
- 오프라인 문자 인식은 내 PC 안에서만 동작하며, API 키는 Windows 자격 증명 관리자에 안전하게 보관됩니다.

## 10초면 익히는 필수 단축키 5개

| 단축키 | 기능 |
| --- | --- |
| **`Shift+F1`** | 화면 캡처 (주석 / 문자 인식 / 번역 / 스크롤 / 녹화) |
| **`Shift+F3`** | 클립보드 이미지 또는 텍스트 화면 고정 |
| **`Ctrl+Alt+D`** | 선택한 텍스트 바로 번역 |
| **`Ctrl+Shift+S`** | 캡처 후 즉시 텍스트 인식 및 복사 |
| **`Ctrl+Shift+O`** | 캡처 후 즉시 번역 |
