# SnapMind 需求文档 v0.3

> 一句话定位：屏幕上看到外语时，用最少的操作看懂它，需要时还能留住它。
> 设计稿与可操作原型：画布「SnapMind 美术方案」（云母浅色 / 深夜、截图编辑态、设置、贴图、设计规范）。原型源码备份在 `design/prototype/`。

## 1. 核心模型

所有功能都归结为一条主线：**文字来源 → (识别) → (翻译 / 整理) → 呈现**。

```
截图（图片） ─→ 识别 ─┬─→ 纯文本（按段落 / 按行，可只选一部分）
                     ├─→ Markdown / LaTeX 公式 / 表格（Excel · MD · HTML）
                     └─→ 翻译 ─→ 卡片 / 原位覆盖 / 贴图
选中文字 / 剪贴板 ──────────→ 翻译
```

### 1.1 识别与翻译的后端

| 槽位 | 可选后端 |
|---|---|
| 识别（图片 → 文字） | 本地 OCR（PaddleOCR ONNX，离线，带行和段落坐标）· 大模型（视觉） |
| 翻译（文字 → 译文） | 机器翻译（Google / 微软 / DeepL）· 大模型 |

- 联网 OCR 已删除：本地 OCR 加视觉大模型已经覆盖所有场景。
- **一步到位**（开关）：识别和翻译交给同一个视觉大模型，一次调用。
- 原位覆盖需要文字坐标，只有本地 OCR 能提供。识别用大模型或一步到位时，结果用卡片展示。

### 1.2 备用链（fallback）

- 默认开启。翻译、识别、一步到位各有一条有序链，第 1 个是首选。
- 请求失败、超时（默认 8 秒）或返回空结果时，自动换下一个。
- 链里可以混合大模型和机器翻译，可以上移、下移、删除、添加。一步到位链的最后一项可以是「降级为：本地 OCR → 翻译链」。
- 结果卡片和翻译历史会标出实际使用的后端，例如「deepseek-chat 超时，已切换到 DeepL」。

### 1.3 提示词

在「提示词」页按任务分开设置，可以恢复默认：识别 · 翻译 · 一步到位 · Markdown。

可用变量：`{target_lang}` `{source_lang}` `{glossary}` `{text}`。

### 1.4 模型服务

- 按服务商管理：添加服务商、填 Key，再从模型列表里勾选要显示的模型。只有勾选的模型才会出现在下拉框和备用链里。
- 内置服务商：DeepSeek、Anthropic、Google Gemini、OpenAI、OpenRouter、Ollama（本地），以及自定义（OpenAI 兼容）。
- 接口格式：OpenAI 兼容、Claude 原生、Gemini 原生。
- 模型带标签（视觉 / 文本 / 推理 / 本地）。识别和一步到位只能选视觉模型。
- API Key 只存在系统凭据库里。

## 2. 全局快捷键（默认值，均可自定义）

| 快捷键 | 动作 |
|---|---|
| `Shift+F1` | 截图，进入编辑态 |
| `Shift+F3` | 贴剪贴板内容（图片贴图片，文字渲染成文字卡片） |
| `Ctrl+Alt+D` | 划词翻译 |
| `Ctrl+Shift+O` | 截图 → 识别 → 翻译 |
| `Ctrl+Shift+S` | 截图 → 识别（复制文字，并弹出可编辑卡片） |

## 3. 截图编辑态

### 3.1 结束规则

- **把结果交出去的动作都会结束截图**：复制、贴图、保存、导出，长截图完成，录屏停止。
- **打开结果卡片不会结束截图**：识别文字、Markdown、公式、表格、翻译。在卡片里点「复制」「贴图」「保存」时才结束。
- `Esc` 逐级退出：弹层 → 保存窗口 → 长截图 / 录屏 → 结果卡片 → 标注 → 截图。
- 有未保存的标注时，按 `Esc` 退出前会确认，确认框里可以勾选「不再询问」。

### 3.2 选区

- 悬停时自动吸附窗口或段落，单击直接选中；滚轮切换上级或下级元素。
- 拖动框选。8 个控制点加四条边都能拖动调整，拖内部移动选区。
- 方向键微调选区 1px，`Shift`+方向键微调 10px。
- 选区左上角显示 `x,y  宽 × 高 px`。

### 3.3 放大镜与取色

- 框选前和框选后都显示：光标旁有像素放大镜、坐标和当前像素颜色值。
- 标注、移动选区、长截图和录屏时隐藏。
- `P` 在 HEX / RGB / HSL 之间切换格式，`C` 复制颜色值，`W A S D` 逐像素移动光标。

### 3.4 操作提示

- 默认在左下角，被选区挡住时自动换到别的角落。内容随状态变化。
- 按 `H` 隐藏后会记住，下次截图默认不显示，再按 `H` 才显示。设置里也有同一个开关。

### 3.5 局部快捷键

| 快捷键 | 动作 |
|---|---|
| `Ctrl+C` / `Enter` | 复制并结束 |
| `Ctrl+T` | 贴图并结束 |
| `Ctrl+S` | 保存…（打开保存窗口） |
| `空格` | 开始 / 退出标注 |
| `Shift+C` | 识别文字 |
| `Shift+Alt+R` | 识别为 Markdown |
| `Ctrl+Q` | 翻译 |
| `L` / `R` | 长截图 / 录屏 |
| `P` / `C` | 切换颜色格式 / 复制颜色值 |
| `W A S D` | 逐像素移动光标 |
| `滚轮` | 选择上级 / 下级元素 |
| `1`–`7` | 标注工具 |
| `Ctrl+Z` | 撤销 |
| `H` | 显示 / 隐藏操作提示 |
| `Esc` | 逐级退出 |

### 3.6 工具条

- 默认顺序：
  - 标注：矩形 / 椭圆、画笔 / 荧光笔、箭头 / 直线、文字、序号、马赛克 / 模糊、橡皮擦、撤销
  - 动作：长截图、录屏、识别文字、Markdown、翻译、贴图、保存
  - 收尾：退出、复制
  - 「⋯ 更多」：公式识别 → LaTeX、表格识别
- 按钮尺寸 30px，工具条内边距 4px，尽量紧凑。
- 带下拉的标注工具可以设置子类型、6 种颜色和 3 档粗细。
- 顺序、显示或隐藏、哪些收进「更多」，都可以在「设置 → 工具栏」里调整（见第 9 节）。

### 3.7 保存窗口（`Ctrl+S`）

- 左边预览，右边设置。
- 保存位置：路径、「打开目录」按钮，以及常用位置快捷切换（桌面 / 图片 / SnapMind / ＋添加）。
- 文件名（按模板预填）和格式（.png / .jpg / .webp），附带格式说明。
- 尺寸：宽和高，可以锁定比例。
- 质量（仅 JPG / WebP），实时显示预计文件大小。
- `Enter` 保存并结束截图；也可以改用系统另存为对话框。
- 设置里可以选 Ctrl+S 的行为：SnapMind 保存窗口 / 系统另存为 / 直接保存到默认目录。

### 3.8 识别结果卡片（都可编辑）

- **识别文字**
  - 默认识别行和段落，可以在「按段落」和「按行」之间切换。
  - 截图上显示检测到的段落框和行框。
  - **右键划过检测框只选一部分**：选中的行加深显示，没选的变淡，卡片只显示选中的部分。右键单击恢复全部。
- **Markdown**：在「编辑」视图修改源码，「预览」视图实时渲染，默认 Obsidian 方言。
- **公式 → LaTeX**：LaTeX 源码可以修改。可以复制 LaTeX，也可以复制 `$$…$$`。
- **表格**：Excel 视图里单元格可以直接改；Markdown 和 HTML 视图里源码可以改。可复制，也可导出 .xlsx。
- **翻译**
  - 原文和译文都是可编辑的文本框，可以只选中、复制其中一部分。
  - 修改原文后点 ↻，按新原文重新翻译。
  - 「卡片 / 覆盖」切换保持不变。

### 3.9 长截图（`L`）

- 选区固定，页面向下滚动，内容自动拼接。
- 选区旁边有实时拼接预览，展示拼出来的长图。
- 底部工具条：当前尺寸（宽 × 已拼接高度）、纵向 / 横向、继续滚动、识别文字、贴图、保存、取消、完成并复制。

### 3.10 录屏（`R`）

- 录制前选择 MP4 或 GIF（GIF 无声音）、帧率，以及是否录制声音。
- 录制中选区边框变红色虚线，显示计时，可以暂停或停止。停止后保存并结束截图。

## 4. 结果呈现

- **卡片**（默认）：原文和译文。
- **原位覆盖**：译文覆盖在原文位置，只覆盖标题和段落，公式和表格保持原样。

## 5. 划词翻译

- 选中文字后按快捷键，程序自动取词并还原原来的剪贴板。
- 结果显示在鼠标旁的小卡片里，点别处消失，点图钉可以固定。

## 6. 贴图

- **工具条**：贴图下方的紧凑工具条。
  - 默认按钮：翻译（原位覆盖）、识别文字、Markdown、标注、保存、复制、更多、关闭。
  - 「更多」：公式、表格、不透明度、鼠标穿透、缩放到 100%、自定义工具条。
  - **防丢失**：工具条和贴图之间有 8px 的透明连接区；鼠标移开后延迟约 0.45 秒才隐藏；鼠标在工具条上或菜单打开时始终显示。
- **基础操作**：置顶，拖空白处移动，滚轮缩放，`Ctrl+滚轮`调不透明度，鼠标穿透，双击或 `Esc` 关闭（进入历史）。
- **自动识别**：贴出后后台自动跑本地 OCR，可以直接拖选图里的文字复制。
- **标注模式**：点「标注」或按 `空格` 进入。
  - 工具条换成和截图编辑态相同的标注工具：矩形 / 椭圆、画笔 / 荧光笔、箭头 / 直线、文字、序号、马赛克 / 模糊、橡皮擦、撤销，带子类型、颜色和粗细；另有复制、完成。
  - 直接画在贴图上，`1`–`7` 切换工具，`Ctrl+Z` 撤销。
  - 标注模式下拖动是绘制，不会移动贴图，双击也不会关闭贴图。
  - 点「完成」、按 `空格` 或 `Esc` 退出，标注保留在贴图上；复制时会带上标注。
- **快捷键**（与截图一致）：`Ctrl+Q` 翻译 / 切回原文、`Shift+C` 识别文字、`Shift+Alt+R` Markdown、`空格` 标注、`Ctrl+C` 复制、`Ctrl+S` 保存、`Ctrl+0` 缩放到 100%、`Ctrl+Shift+X` 穿透、`H` 提示。
- **结果卡片**：在贴图旁可编辑。复制结果后贴图仍保留在屏幕上。

## 7. 历史记录

- 两类：「贴图历史」和「翻译历史」，顶部切换，支持搜索和删除。
- **保留方式**（三选一）：
  - **不限制**：全部保留，手动清理。
  - **按条数**：每类最多保留 N 条。
  - **按空间**（默认 1024 MB）：超出后删除最早的记录，优先清理贴图图片。
- 显示占用空间：总量、贴图与翻译各占多少，按空间限制时显示相对上限的比例。
- 可以打开历史文件夹，也可以一键清空。

## 8. 翻译偏好

- 默认目标语言。原文已是目标语言时，可以翻译成第二语言（默认 English），也可以不翻译。
- 双语对照、保留格式、不翻译列表。
- **自动判断专业术语**：仅在使用大模型时生效，默认开启。

## 9. 工具栏自定义

- 截图工具条和贴图工具条分别设置。
- 拖动排序（也可以用上移、下移按钮）；取消勾选即隐藏。
- 列表中有一条「更多」分隔线，分隔线以下的按钮收进「⋯」菜单，分隔线本身也能拖动。
- 顶部实时预览工具条的样子。可以恢复默认。

## 10. 配置文件

- 所有设置存在 `%APPDATA%\SnapMind\config.json`（Linux 为 `~/.config/SnapMind/config.json`）。可以打开文件夹，也可以复制路径。
- **导出**
  - 可选内容：常规设置、快捷键与工具栏、提示词、模型服务与备用链。
  - API Key 默认不导出；选择导出时，用密码加密。
- **导入**
  - 拖入 .json 文件，或点击选择。可以只导入其中一部分。
  - 导入前自动备份当前配置。
- **自动备份**：修改重要设置前、导入前和每周各备份一次，可以一键恢复。
- **恢复默认设置**：模型服务和历史记录保留，其余还原。

## 11. 入口

- 系统托盘 + 全局快捷键。
- 悬浮球：可选，默认关闭。

## 12. 技术架构

- **框架**：Tauri 2，Rust 后端 + Web 前端。
- **核心层**（共享 Rust 代码）：路由与备用链、服务商适配、提示词、设置与配置文件、历史记录。
- **平台层**：截屏、全局快捷键、读取选中文字、窗口层级、剪贴板、录屏编码。
- **平台路线**：先做 Windows，再做 Linux（KDE Plasma / Wayland：xdg-desktop-portal、GlobalShortcuts portal、layer-shell）。

### 12.1 本地 OCR 的段落和行识别方案

1. **检测与识别**：PaddleOCR（ONNX Runtime）检测每一行文字框，再逐行识别，结果带坐标和置信度。
2. **版面分区**：PP-Structure 版面模型分出正文、标题、表格、公式、图片。若嫌模型太重，退化为按行框投影做分栏。
3. **行 → 段落**：同一栏内按阅读顺序排序，满足以下条件的相邻两行合并为同一段：
   - 行间距 ≤ 0.6 倍行高；
   - 左边缘对齐；
   - 上一行接近栏宽，或末尾没有终止标点；
   - 字号接近。

   首行缩进、行间距突变、字号变化，都视为新段落的开始。
4. **拼接**：中日韩文字直接拼接；拉丁文字补空格，行尾连字符要拆掉。
5. **表格与公式**：表格用 SLANet 还原结构，再转成 Excel、Markdown 或 HTML；公式用 PP-FormulaNet 或 UniMERNet，失败时退回大模型。
6. **局部选择**：每一行都带唯一编号和坐标，右键划选时按矩形相交挑出行，再按段落规则重新拼接文本。

**待验证**：上面的阈值要在真实截图样本上调参，样本包括网页、PDF、代码、聊天记录、双栏论文。写引擎时先准备样本，并建立评测脚本。

## 13. 外观主题

- 只有一套视觉风格：**云母（Mica）**。明暗模式在设置里选「跟随系统 / 浅色 / 深夜」，默认跟随系统。

| 令牌 | 浅色 | 深夜 |
|---|---|---|
| 底色 | `#E6EBF2` | `#0E1219` |
| 玻璃表面 | 白 82% + 模糊 24px | `#1E2530` 80% + 模糊 24px |
| 主文字 | `#0F172A` | `#E8ECF2` |
| 次要文字 | `#475569` | `#9BA6B5` |
| 描边 | 黑 6% | 白 7%，另加顶部 1px 高光 |
| 强调色 | `#2563EB`（白字） | `#60A5FA`（深色字） |
| 截图遮罩 | `rgba(15,23,42,.45)` | `rgba(3,6,12,.6)` |

- 强调色可选蓝、天蓝、紫、绿，深夜模式下自动提亮。
- 组件只引用设计令牌，切换即时生效。

## 13.1 界面语言与通用设置

- 设置里有「通用」页（导航第一项），放界面语言和开机自动启动（托盘菜单里也有同一个开机开关）。
- **显示语言**：默认「跟随系统」，系统语言不在支持列表里就用 English；也可以手动选。切换立即生效，所有已打开的窗口（设置、遮罩、贴图、卡片、托盘菜单）一起换。
- 支持 10 种：简体中文（源语言）、繁體中文、English、日本語、한국어、Español、Français、Deutsch、Русский、Português (Brasil)。语言名始终用各自的母语写法。
- 实现：代码里直接写中文，`t('中文')`（前端，`ui/src/lib/i18n.svelte.ts`）和 `tr("中文")`（后端，`snapmind_core::i18n`）按中文原文查词典，缺译文就显示中文原文。词典在 `ui/src/locales/`（界面）和 `crates/snapmind-core/locales/`（后端），`node scripts/i18n.mjs` 检查缺译、列出待翻译句子、合并译文；vitest 里的词典测试保证新增的文案都有 9 种译文。
- 大模型提示词、日志文件、开发调试页不翻译。

## 14. 已确认的决定

- 翻译、识别、大模型接口失败时，默认自动切换备用，链路可自定义。
- 截图选区右侧那列圆形按钮暂时不做。
- 代码托管在 GitHub 私有仓库。
