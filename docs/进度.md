## 决策记录

- **M0.1 前端工程布局**：`package.json` 放仓库根目录（Tauri CLI 从根目录运行最省事），Vite 配置放 `ui/vite.config.ts`，Vite 的 root 是 `ui/src/entries`，每种窗口一个子目录入口，窗口 URL 形如 `settings/index.html`。构建产物在 `ui/dist`。
- **M0.1 版本号单一来源**：版本号只写在根 `Cargo.toml` 的 `[workspace.package]`，各 crate 和 Tauri 都从这里继承；`tauri.conf.json` 不写 version。
- **M0.1 TypeScript 用 6.x**：svelte-check 4.7 的 peer 依赖还不支持 TS 7，先锁 `^6`，等 svelte-check 跟上再升。
- **M0.1 应用标识**：`app.snapmind.desktop`。应用图标自己画（`design/icon/snapmind.svg`：蓝色圆角方块 + 取景框四角 + 四角星），用 `tauri icon` 生成各尺寸，只保留桌面端需要的文件。
- **M0.1 不入库**：`src-tauri/gen/`（Tauri 构建时自动生成的权限描述）。
- **M0.1 发布构建**：release 配置开 LTO、`opt-level = "s"`、`panic = "abort"`、strip，优先控制安装包体积（预算 ≤ 25 MB）。
