## 为什么大家装上 SnapMind 就离不开了？

以前为了截个图、提个字、翻译外语、录个小视频，电脑里得同时装三四个臃肿软件、记一堆快捷键。**现在，只需要一个 10 MB 的 SnapMind：**

- **看外语网页、游戏界面、PDF 论文、软件报错看不懂？** 鼠标框一下，**译文直接盖在原图上**，底色和字号自动贴合，就像软件本来就是中文的一样！
- **图片或 PPT 里有一张大表格，懒得一个字一个字敲进 Excel？** 一键识别成可编辑表格，**直接复制粘贴进 Excel / Word，连合并单元格都帮你保得好好的**！
- **写文档、做作业、敲代码时要把参考图一直放手边？** **一键钉在屏幕最前面**，还能直接用鼠标从贴图里选字复制、画重点、调半透明！
- **聊天记录太长截不全？想录个 10 秒操作演示发给同事？** **滚动长截图 + 录屏（MP4 / GIF）全都内置**，录完自动复制到剪贴板，Ctrl+V 直接发出去！

## 六大核心亮点，每一项都超顺手

### 1. 秒开截图，标注顺滑到飞起
- 按下 **`Shift+F1`** 瞬间定格画面，多显示器、高分屏一样丝滑。
- 鼠标滑过哪里就自动帮你对准窗口和按钮，截出来的图方方正正。
- 自带放大镜取色、箭头、方框、荧光笔、文字、序号、高清马赛克；复制一次，微信、QQ、飞书、文档和文件夹随便粘贴。

### 2. 断网也能用的免费高精度识字（文字 · 表格 · 公式 · Markdown）
- **免费、离线、不上传隐私**：装好本地识字包后，断网也能精准识别中、英、日、韩等多国文字，不用花一分钱。
- **想要哪几行就点哪几行**：识别后可以直接在图上点选保留或去掉某一行，不用再复制一堆废话回来手动删。
- **表格一键进 Excel**：识别完直接网页式预览、点进去就能改字，一键粘贴进 Excel / Word，或直接导出 `.xlsx` 文件。
- **公式 & 长文排版**：论文里的复杂数学公式一键转成可直接粘贴的公式代码；整篇文章一键保留标题和列表导出 Markdown。

### 3. 像母语一样读懂全屏的 AI 翻译
- **原图覆盖翻译**：译文直接盖在截图对应位置，自动跳过代码、数字和公式，看外语软件、漫画、资料毫无违和感。
- **随处划词翻译（`Ctrl+Alt+D`）**：在浏览器、PDF、聊天软件里选中任意外语，按一下立刻在鼠标旁弹出可拖动小卡片；点一下图钉固定后，还能在同一张卡片里连续查词。
- **内置 24+ 主流大模型与翻译引擎**：DeepSeek、ChatGPT、Claude、Gemini、通义千问、Kimi、智谱、豆包、DeepL、微软/谷歌翻译，甚至你本机装的 **Ollama / LM Studio 本地大模型** 全都支持！还能排好备用顺序，一家超时自动切下一家。

### 4. 用过就回不去的屏幕贴图
- 按 **`Ctrl+T`** 把截图钉在最顶层，或者按 **`Shift+F3`** 把剪贴板里的图片/文字直接变成悬浮卡片。
- **贴图上直接选字复制**：贴出来的图片后台自动识字，鼠标一拖就能把图里的字拷走。
- 滚轮自由缩放、调半透明对比设计稿、原位涂鸦标注、鼠标穿透（不挡操作）一应俱全。
- 关掉的贴图和翻译会自动进历史记录，随时搜回来重新贴出；电脑意外重启还能自动恢复没关的贴图。

### 5. 滚动长截图 & 轻量录屏
- **滚动长截图（`L`）**：自动或手动滚屏，把超长网页、长聊天记录无缝拼成一张高清长图，自动裁掉滚动条和重复顶栏。
- **区域录屏（`R`）**：框选哪块录哪块，支持带系统声音的 **MP4 视频** 和动图 **GIF**，录完自动复制到剪贴板，打开聊天框直接粘贴发送。

### 6. 小巧、好看、守住你的隐私
- 安装包仅约 **10 MB**，几乎不占内存；浅色 / 深夜双主题 + 4 种配色，支持 10 国语言，颜值在线。
- 截图工具栏、快捷键、贴边悬浮球全都能按自己的顺手习惯随便调。
- **隐私安心**：本地识字绝不联网上传；你的 API 密钥只存放在 Windows 系统安全凭据保险箱里，绝不明文保存。

## 10 秒记住 5 个最常用快捷键

*（所有快捷键都可以在 **设置 → 快捷键** 里改成你习惯的按键）*

| 快捷键 | 做什么用 |
| --- | --- |
| **`Shift+F1`** | 开始截图（标注 / 识字 / 翻译 / 长截图 / 录屏都在这里） |
| **`Shift+F3`** | 把剪贴板里的图片或文字直接贴在屏幕上 |
| **`Ctrl+Alt+D`** | 划词翻译（先选中文字再按） |
| **`Ctrl+Shift+S`** | 截图并立刻识字复制 |
| **`Ctrl+Shift+O`** | 截图并立刻翻译 |
